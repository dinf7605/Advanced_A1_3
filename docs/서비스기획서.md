## 1. 서비스 개요

### 해결하려는 문제

노트 필기는 **쓰는 순간이 아니라 다시 볼 때** 효과가 납니다. 그런데 실제로는 두 가지가 막습니다.

| 문제 | 왜 생기는가 |
|------|-------------|
| 필기해 놓고 다시 안 본다 | 분량이 많아 **어디부터 볼지** 모른다 |
| 다시 읽어도 남지 않는다 | 재독만 하고 **인출 연습(떠올리기)**을 하지 않는다 |

### 목적

노트 하나를 붙여넣는 **한 번의 입력**으로 위 두 가지를 동시에 해결합니다.

- 어디부터 볼지 알려주는 **3줄 요약**
- 뭘 외워야 하는지 알려주는 **핵심 용어 3~5개**
- 읽기가 아니라 떠올리기를 시키는 **확인 퀴즈 5문항**

> 이름은 되새김질(반추)에서 왔습니다. 한 번 삼킨 내용을 다시 꺼내 씹어야 소화된다는
> 학습법을 그대로 이름으로 썼습니다.

## 2. 타겟 사용자

| 구분 | 1순위 | 2순위 |
|------|-------|-------|
| 누구 | **시험·자격증을 준비하는 학생 / 부트캠프 수강생** | 아티클·문서를 많이 읽는 직장인 |
| 상황 | 수업 직후, 필기는 있는데 복습할 시간이 30분뿐 | 읽은 아티클을 나중에 다시 못 찾음 |
| 지금 하는 일 | 노트를 처음부터 다시 읽는다 | 북마크만 하고 끝 |
| 불편 | 분량 대비 시간이 없고, 읽어도 남지 않는다 | 요약이 없어 다시 열어보지 않는다 |
| 되새김이 주는 것 | **30초 만에** 요약 + 외울 것 + 확인 문제 | 요약과 용어가 남아 재방문 가치가 생김 |

### 대표 사용 시나리오

1. 수업이 끝나고 노트 앱에서 오늘 필기를 전체 복사한다.
2. 되새김 → **[되새김]** 탭에 붙여넣고 과목을 "IT", 난이도를 "보통"으로 고른다.
3. 10초쯤 뒤 요약 3줄 · 용어 4개 · 퀴즈 5문항이 나온다.
4. 퀴즈를 풀면 즉시 채점되고 해설이 펼쳐진다.
5. **[내 기록]**에 자동 저장돼서 지하철에서 다시 열어본다.

## 3. 페이지 구성

**단일 페이지 + 해시 라우팅**으로 4개 섹션을 전환합니다.
상단 고정 메뉴의 링크를 누르면 URL이 `#/study`처럼 바뀌고, JavaScript가 해당 섹션만 표시합니다.

| # | 섹션 | 주소 | 하는 일 | AI |
|---|------|------|---------|:--:|
| 1 | **홈** | `#/` | 서비스 소개, 3단계 사용법, 샘플 결과 미리보기 | — |
| 2 | **되새김** | `#/study` | 노트 입력 → 요약·용어·퀴즈 출력, 퀴즈 채점 | ✅ |
| 3 | **내 기록** | `#/history` | 브라우저에 저장된 최근 10건 열람·삭제 | — |
| 4 | **가이드 · 문의** | `#/guide` | 학습법 가이드, FAQ, 문의 폼 | — |

### 메뉴 이동 방식

| 화면 | 동작 |
|------|------|
| 데스크톱 (1024px~) | 상단 가로 메뉴. 현재 섹션은 밑줄 + `aria-current="page"` |
| 태블릿 (600~1023px) | 가로 메뉴 유지, 카드 2열 |
| 모바일 (~599px) | 햄버거 버튼 → 전체 화면 오버레이 메뉴. 링크를 누르면 자동으로 닫힘 |

- 브라우저 **뒤로 가기**로도 섹션이 전환됩니다 (`hashchange` 이벤트).
- 알 수 없는 주소(`#/asdf`)는 빈 화면 대신 **홈으로 되돌립니다.**

## 5. AI 기능 명세

### 5-1. 입력

| 필드 | 형태 | 필수 | 규칙 |
|------|------|:----:|------|
| **노트** | 여러 줄 텍스트 입력 | ✅ | 공백 제외 **100자 이상 4,000자 이하** |
| **과목** | 선택 (드롭다운) | — | 일반 / IT / 경영 / 과학 / 어학 · 기본값 `일반` |
| **난이도** | 선택 (라디오) | — | 쉬움 / 보통 / 어려움 · 기본값 `보통` |

**과목과 난이도가 결과를 어떻게 바꾸는가**

| 선택 | 결과에 나타나는 차이 |
|------|---------------------|
| 과목 **IT** | 용어에 원어를 병기한다 — `메서드(method)`, `상태 코드(status code)` |
| 과목 **경영** | 문항에 사례가 붙는다 — "사용자가 상품 목록 페이지를 로드할 때…" |
| 과목 **어학** | 질문이 용법 중심이 된다 — "어느 헤더에 어떤 값을 써야 하나?" |
| 과목 **과학** | 조건이 바뀌면 결과가 어떻게 되는지 묻는 문항이 들어간다 |
| 난이도 **쉬움** | 노트에 그대로 적힌 사실 확인 (용어·정의) |
| 난이도 **어려움** | 새로운 상황에 적용하거나 여러 개념을 연결해야 풀리는 문항 |

> 이 표는 **실제로 호출해 비교한 결과**입니다. 처음에는 과목 이름만 프롬프트에
> 넣었는데 결과가 거의 같아서, 과목별 **지시문**을 함께 보내도록 고쳤습니다.

- 입력창 아래에 **실시간 글자 수 카운터**가 있고, 4,000자를 넘으면 빨갛게 표시됩니다.
- [예시 넣기] 버튼으로 샘플 노트를 채워 바로 체험할 수 있습니다.
- **검증은 화면과 서버 양쪽에서 합니다.** 화면 검증은 편의(UX)이고,
  서버 검증은 보안입니다 — 화면 검증만 있으면 도구로 우회해 대량 요청을 보낼 수 있습니다.

**왜 100자 하한을 두는가** — 한 문장을 넣으면 요약할 것도 문제로 낼 것도 없어서
모델이 내용을 지어냅니다. 결과 품질 문제를 **입력 검증으로** 막는 편이 낫습니다.

**왜 4,000자 상한인가** — 응답 시간이 길어져 타임아웃 위험이 커지고, 입력량이 곧 API 사용량입니다.
넘치면 **자르지 않고 사용자에게 알립니다.** 조용히 자르면 뒷부분이 빠진 이유를 알 수 없습니다.

### 5-2. 출력

| 항목 | 개수 | 형태 |
|------|------|------|
| **주제** | 1 | 노트의 주제를 한 줄로 |
| **요약** | 정확히 3개 | 각 한 문장(80자 이내) |
| **핵심 용어** | 3~5개 | 용어 + 뜻. **노트에 실제로 등장한 표현만** |
| **퀴즈** | 정확히 5문항 | O/X 2문항 + 객관식 3문항. 각각 보기·정답·해설 |

- 화면에는 카드 4장(주제 / 요약 / 용어 / 퀴즈)으로 표시되고, 위에서 아래로 순서대로 나타납니다.
- 퀴즈는 라디오 버튼으로 풀고 [채점하기]를 누르면 **점수 · 정오 표시 · 해설**이 나옵니다.
- 정오는 색뿐 아니라 ✅/❌ 아이콘으로도 구분합니다(색각 이상 대응).
- **해설은 채점 전에는 화면에 넣지 않습니다.**

**모델에게 준 규칙**

1. 노트에 없는 사실을 추가하지 않는다.
2. 핵심 용어는 노트에 실제로 등장한 표현만 쓴다.
3. 객관식 오답은 노트의 다른 내용에서 가져와 그럴듯하게 만든다.
   "위 보기 모두" 같은 회피형 보기를 쓰지 않는다.
4. 해설은 노트의 근거를 들어 한두 문장으로 쓴다.

### 5-3. 실패 처리 기준

**원칙: 화면이 아무 말 없이 멈추는 경우는 0이어야 한다.**
로딩이 끝났는데 결과도 오류도 없는 상태가 가장 나쁜 실패입니다.

| 구분 | 상황 | 사용자에게 보이는 것 | 다시 시도 |
|------|------|---------------------|:--------:|
| **차단** | 노트가 비어 있음 | "되새길 노트를 먼저 붙여넣어 주세요." | — |
| **차단** | 100자 미만 | "내용이 너무 짧아요. 100자 이상 붙여넣으면 요약과 퀴즈를 만들 수 있어요." | — |
| **차단** | 4,000자 초과 | "한 번에 4,000자까지 가능해요. 나눠서 되새겨 보세요." | — |
| **차단** | 10초 내 재요청 | 버튼에 남은 초 표시 | — |
| **거절** | 짧은 시간에 반복 호출 | "잠시 쉬어갈까요? 1분 뒤에 다시 시도할 수 있어요." | ✅ |
| **외부 실패** | AI 서버 오류 (4xx/5xx) | "지금은 되새김이 잠시 쉬고 있어요. 잠시 후 다시 시도해 주세요." | ✅ |
| **외부 실패** | 응답 지연 · 타임아웃 | "생각이 길어졌어요. **노트를 조금 줄이면** 훨씬 빨라져요." | ✅ |
| **외부 실패** | 인터넷 끊김 | "인터넷 연결을 확인해 주세요." | ✅ |
| **결과 불량** | 응답 형식이 규격과 다름 | "결과를 다듬는 데 실패했어요. 한 번 더 시도하면 대개 잘 나와요." | ✅ |
| **결과 불량** | 모델이 생성을 거절 | "이 내용으로는 퀴즈를 만들기 어려워요. 다른 노트로 시도해 주세요." | — |

**세 가지 설계 원칙**

1. **차단은 요청을 보내지 않습니다.** 빈 입력으로 [되새기기]를 눌러도 네트워크 요청이 0건입니다.
2. **오류 메시지는 사용자가 할 수 있는 행동을 줍니다.**
   "타임아웃이 발생했습니다"(✗) → "노트를 조금 줄이면 훨씬 빨라져요"(✓)
3. **내부 사정은 사용자에게 알리지 않습니다.** 키가 없거나 인증이 실패해도 화면에는
   "일시적인 문제"라고만 표시하고, 원인은 서버 로그와 `/api/health`로 확인합니다.

**응답 처리 4단계** — AI 응답은 그대로 쓸 수 없어서 네 단계를 거칩니다.

1. 응답이 중간에 잘렸는지 확인 (잘렸으면 형식이 깨져 있음)
2. 코드블록 표시(```` ``` ````)가 붙어 왔으면 벗겨냄
3. JSON 해석 — 실패하면 **정확히 1회만** 다시 요청
4. **의미 검증** — 정답이 보기 안에 있는지, 개수가 맞는지 등

> **해석에 성공했다고 쓸 수 있는 결과가 아닙니다.** 정답이 보기 밖에 있으면 채점이 깨집니다.
> 그리고 4단계 실패는 **다시 요청하지 않습니다** — 응답 시간과 사용량이 2배가 되므로
> [다시 시도] 버튼을 사용자에게 맡깁니다.

## 6. 기술 구성

### 요청 흐름

```
[브라우저]                                [Vercel]                   [AI]
 index.html  HTML — 무엇이 있는가(구조)
 css/*.css   CSS  — 어떻게 보이는가(표현)
 js/*.js     JS   — 무엇이 일어나는가(동작)
      │
      │ ① 사용자가 노트를 붙여넣고 [되새기기] 클릭
      │ ② fetch('/api/summarize', { method:'POST', body: ... })
      ▼
   ─────── 인터넷 ───────
                                 api/summarize.py
                                  │ ③ 입력 검증
                                  │ ④ 환경 변수에서 API 키를 읽음
                                  │    ★ 키가 존재하는 유일한 곳 ★
                                  │ ⑤ AI 호출 ──────────────────►
                                  │ ⑥ 응답 검증 4단계 ◄───────────
                                  │ ⑦ JSON 반환
      ┌───────────────────────────┘
      ▼
   js/study.js
      │ ⑧ 응답을 화면 요소로 만들어 붙임
      ▼
 [요약·용어·퀴즈가 화면에 나타남]
```

### 키를 서버에 두는 이유

브라우저로 내려간 것은 **전부 사용자가 볼 수 있습니다.** JavaScript 파일에 넣든,
난독화하든, 빌드할 때 주입하든 결과는 같습니다 — 최종 파일에 문자열로 들어가면 끝입니다.

그래서 브라우저는 **우리 서버에게만** "요약해줘"라고 말하고, 키를 아는 것은 서버뿐입니다.
`api/` 폴더는 **키를 숨길 수 있는 유일한 장소**이고, 이것이 이 서비스가 서버리스 함수를
쓰는 진짜 이유입니다.

## 7. 개인정보 처리

| 데이터 | 어디에 저장되나 | 외부 전송 |
|--------|----------------|-----------|
| 붙여넣은 노트 원문 | **저장하지 않음** (요청 처리 후 사라짐) | AI 처리 목적으로만 |
| 요약·용어·퀴즈 결과 | 사용자 **브라우저(localStorage)**, 최근 10건 | ❌ |
