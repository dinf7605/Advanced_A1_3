## 데스크톱 (브라우저 창 1280px 이상)

### 01_home_desktop.png — 홈
```
https://advanceda13.vercel.app/#/
```
히어로("붙여넣으면, 되새길 것만 남습니다") + 3단계 카드가 **가로 3열**로 보이게.
상단 네비 4개가 다 보이도록 창을 충분히 넓게.

### 02_study_input_desktop.png — 노트 입력 상태
```
https://advanceda13.vercel.app/#/study
```
1. **[예시 넣기]** 버튼 클릭 → textarea가 채워짐
2. 과목을 **IT**, 난이도를 **보통**으로 선택
3. 글자 카운터에 `501 / 4,000자`가 보이는 상태로 촬영

> 입력 UI(폼·드롭다운·라디오·카운터)가 다 보이는 것이 요건 5의 "입력 UI 제공" 증빙입니다.

### 03_study_loading.png — 로딩 ⏱️ 타이밍 주의
[되새기기]를 누른 **직후 8초 안에** 찍어야 합니다.
스켈레톤 카드 3개 + "요약하는 중이에요… (보통 10초 안팎)" + 버튼의 스피너가 보입니다.

> **놓치기 쉬우니 이 방법을 쓰세요** — 화면 녹화를 켜고 제출한 뒤 프레임을 캡처하거나,
> `?mock=1`로 접속하면 1.2초 지연이 걸려 여유 있게 찍을 수 있습니다.

### 04_study_result_desktop.png — ⭐ AI 결과 (가장 중요)
결과가 나온 뒤 **주제 · 요약 3줄 · 핵심 용어 카드**가 한 화면에 들어오게.
페이지 전체 캡처(F12 → Ctrl+Shift+P → "Capture full size screenshot")를 쓰면 편합니다.

> **이 한 장이 "AI API 연동 기능(입력 → 결과 출력)"의 증빙입니다.** 반드시 실제 결과로 찍으세요.

### 05_quiz_graded.png — 채점 결과
1. 퀴즈 5문항을 풀고 **[채점하기]** 클릭
2. `5문항 중 N개 정답` 점수 배지 + ✅/❌ 표시 + **해설**이 펼쳐진 상태

> 일부러 몇 개는 틀리게 고르면 ✅와 ❌가 **둘 다** 보여서 더 좋습니다.

## 모바일 (375 × 812)

F12 → 좌상단 기기 아이콘(Ctrl+Shift+M) → **iPhone 15** 또는 폭 375 직접 입력.
**실제 휴대폰으로 찍으면 더 좋습니다** (요건 4의 "직접 확인" 증빙이 확실해짐).

### 06_home_mobile.png — 홈 (모바일)
```
https://advanceda13.vercel.app/#/
```
1열 레이아웃 + **햄버거 버튼**이 보이게. 가로 스크롤이 없어야 합니다.

### 07_study_result_mobile.png — AI 결과 (모바일)
같은 375px에서 결과 화면. 퀴즈 보기가 넘치지 않고 잘 접히는지 보이게.

> 06·07 두 장이 "반응형으로 모바일에서도 정상 표시" 증빙입니다.
> 여유가 되면 **햄버거 메뉴를 연 상태** 한 장을 `06b`로 추가하면 메뉴 이동까지 증명됩니다.

## 실패 처리 · 보너스

### 08_error_timeout.png — 실패 안내 ⭐ 서버 없이 만들 수 있음
```
https://advanceda13.vercel.app/?mock=timeout#/study
```
1. [예시 넣기] → [되새기기]
2. 1.2초 뒤 **"생각이 길어졌어요. 노트를 조금 줄이면 훨씬 빨라져요."** + [다시 시도] 버튼

> **실패 화면을 인위적으로 만들 수 있게 목업 모드를 넣어둔 이유가 이것입니다.**
> 요건 5의 "실패 처리 안내 메시지" 증빙이며, 진짜 장애를 기다릴 필요가 없습니다.
>
> 여유가 되면 두 장 더:
> - `08b_error_api.png` — `?mock=error` (API 오류)
> - `08c_error_empty.png` — 빈 채로 [되새기기] → "되새길 노트를 먼저 붙여넣어 주세요."
>   (이건 **네트워크 요청 0건**으로 막히는 화면이라 설명하기 좋습니다)

### 09_dark_mode.png — 다크 모드 (보너스 A)
우상단 🌙 버튼을 눌러 다크로 전환한 뒤 **결과 화면**을 찍으면 한 장으로 두 가지가 증명됩니다.
